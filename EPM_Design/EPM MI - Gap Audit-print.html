Internal Design Review
Gap audit: live implementation vs Direction C.
A screen-by-screen analysis of where the live site diverges from the intended Direction C system — Executive / Client-facing. Prioritized issues, classification by type (visual / interaction / bug), exact fixes, and a Claude Code implementation brief.
Section 1
Screen-by-screen gap analysis
Screen 1 — Homepage
Live — what's there
  • Dark navy background, no light-mode canvas
  • Top bar: eye icon + search box + hamburger-style density toggle + avatar — no section navigation
  • Three "Open X" launch cards (Markets, Forecasting, Portfolios) — nav workaround
  • Featured watchlist: stock cards with sparklines, prices, signal labels ("Strong uptrend" / "Downtrend")
  • Portfolio Watchlist panel alongside — two-column layout, card style slightly different
  • Latest Big News: three-column text grid, no kickers or source hierarchy
  • Footer: "EPM Market Intelligence" tiny text — wordmark appears nowhere prominently
Direction C — intended
  • Light canvas (#F4F6FA), white cards, navy masthead only
  • Full persistent nav in masthead: Homepage, Markets, Forecasting, Model Portfolios, Fund Search, Research, Watchlists
  • No launch cards — nav does the job
  • KPI strip: 5 index cards with sparkline + soft pill delta
  • Hero editorial card (lead story) + today's calendar right rail
  • Gainers / Decliners / Newswire in a 3-col row — consistent card shell
  • EPM wordmark in masthead, amber logotype, always visible
Headline gap: The homepage is doing navigation's job with the three "Open X" cards because the top bar has no section links. Remove those cards, add the nav. The dark-mode-only palette is the single biggest divergence from Direction C's visual system — everything else flows from fixing that.
Screen 2 — Markets
Live — what's there
  • Navigation: completely absent — no way to reach other sections
  • Page is extremely tall; almost everything shows "Loading…" empty states
  • Chart panels are large black rectangles — zero content visible
  • Section headers exist (CHARTS, SENTIMENT & POSTURE, etc.) but hierarchy is weak — same weight as body text
  • "Sign in" button appears in the top-right — inconsistent with logged-in state shown on Homepage
  • Loading states: plain text "Loading indexes…" / "Loading trend data…" — no skeleton, no shimmer
  • No timestamp or data-as-of indicator on unavailable panels
Direction C — intended
  • Persistent nav always visible — Markets tab highlighted with amber underline
  • Sub-tabs: Overview / Equities / Rates / FX / Commodities / Crypto (segmented control)
  • Featured chart (SPX) + global indices right rail — data-first above fold
  • Sector performance: 8 metric cards with sparklines — compact, scannable
  • Gainers / Decliners: table-style rows with mono numerics + soft delta pills
  • Skeleton loaders while data fetches; panels labeled with data-as-of timestamp
Headline gap: This page is broken in its current state — the empty loading panels create a "ghost layout" that communicates nothing. Even when data loads, navigation is absent. This is the highest-severity page.
Screen 3 — Forecasting (MAG7 Dashboard)
Live — what's there
  • Navigation: present in top bar but minimal — no section links
  • Real data shows — this page works best of all five
  • Consensus Forecast cards per ticker: good data density, confidence badges are amber (on-brand)
  • Model Leaderboard: trophy/medal icons feel gamey for a professional platform
  • "Daily Commentary / Model Pipelines" tabs: good structure but tabs are hard to read (low contrast)
  • Page title "MAG7 Forecast Dashboard" is specific — no broader Forecasting section context
  • Card borders are dark on dark — individual items blend together
Direction C — intended
  • Eyebrow "EPM Research" + large display title "Forecasting"
  • Summary scenario cards (3-col): probability + delta vs consensus + EPM take
  • House views table: Metric / Consensus / EPM / Δ / Confidence (bar, not badge)
  • Confidence shown as 3-segment bar (Low/Med/High) — not a colored text badge
  • Fan chart for rate path with labeled scenarios
  • Muted, professional language — no trophy/gamification elements
Headline gap: The Forecasting page has the right data but the wrong framing. It's scoped to MAG7 instead of presenting as the top-level Forecasting section. Gamification elements (trophies) undermine credibility. The broader section structure (scenario cards, consensus table) is missing.
Screen 4 — Model Portfolios
Live — what's there
  • Navigation: absent once on this page
  • "Portfolio Leaders / Portfolio Laggards" framing is interesting but creates cognitive split
  • Card grid: 2-col for leaders, 2-col for laggards — too many cards, not enough hierarchy
  • Individual fund cards: price + sparkline + signal + 1M/YTD/Beta metrics + description blurb
  • Description text inside cards is too long — breaks scan rhythm
  • Portfolio Holdings section below: similar card pattern, very long scroll
  • No portfolio-level metrics (YTD, Sharpe, risk profile) — only individual fund cards
Direction C — intended
  • Two-up hero cards for featured portfolios: allocation bar + 4 KPIs + CTA buttons
  • Remaining models in a compact table: Name / Strategy / YTD / 1Y / Sharpe / Risk / Action
  • Filter row: All / Conservative / Moderate / Aggressive / Thematic
  • Portfolio-level framing first, holdings drill-down on detail page
  • No description blurbs inside cards — information on the detail page
Headline gap: The live page presents fund-level data where portfolio-level data is needed. Users see individual fund cards when they should see portfolios first. The scroll length is extreme — a table for the bottom portfolios would cut this by 70%.
Screen 5 — Fund Search / Ticker Detail (AAPL)
Live — what's there
  • Navigation: absent — single back path via browser
  • Search input with "AAPL" pre-filled — works as a search entry point
  • Detail view shows immediately with no results list step
  • Price chart: functional, good range selector (YTD / 6M / 1Y…)
  • Snapshot panel: description, recent news items — feels like a news aggregator
  • Data tables: Price, Returns, Risk, Trend, Fundamentals, Sentiment — dense but good
  • Deep Analysis Lab: two large amber CTA buttons — visually dominant, unclear value prop
  • "Powered by Gemini / Anthropic / EPM" attribution bar — trust signal but visually noisy
Direction C — intended
  • Search surface: filter chips (Category / Expense / AUM / Rating / 1Y Return) + results table
  • Results table: Ticker / Name / Category / AUM / Expense / YTD / 1Y / Trend sparkline / Rating
  • Ticker detail as a second step / drill-down, not the landing state
  • Data tables consistent with the rest of the product (same header style, row height, mono numerics)
  • AI analysis as a secondary affordance — not the primary CTA
Headline gap: The page skips the list/search step and goes straight to detail. The "Deep Analysis Lab" section with two large amber buttons visually overwhelms the actual financial data. The attribution bar at the bottom feels like a footnote that got promoted.
Section 2
Top 10 issues — priority order
Critical → High → Medium
1
No persistent navigation — users get stranded on every non-homepage screen Critical Interaction
Once a user navigates away from the homepage, there are no section links to reach Markets, Forecasting, Portfolios, or Fund Search. The only escape is the browser back button. The homepage compensates with three "Open X" launch cards — a workaround that shouldn't exist. The top bar shows a search box, a density toggle icon, and an avatar, but no navigation.
Fix: Add a full section nav to the top bar on every page. Use the Direction C pattern: dark navy bar, product name left, section links centered, search + avatar right. Active section gets amber bottom border. This is the single highest-leverage change — it fixes the navigation problem and removes the need for the homepage launch cards.
2
Markets page is a ghost layout — empty panels dominate the screen Critical Bug / State
The Markets page shows mostly empty black rectangles where charts should be, with "Loading indexes…" / "Loading trend data…" plain-text placeholders. Whether this is a slow data fetch or a data availability issue, the result looks broken. No skeleton loaders, no error states, no "data unavailable" messaging with context.
Fix: Implement a three-state system for every data panel: (1) Loading — animated shimmer skeleton at the correct panel height; (2) Loaded — actual content; (3) Unavailable — placeholder with a message like "Data temporarily unavailable · Last updated [timestamp]" and a retry affordance. Never show a black rectangle.
3
Dark-mode-only palette diverges entirely from Direction C's light-mode system High Visual
Direction C is a light-mode-first design: off-white canvas (#F4F6FA), white cards, dark navy masthead only. The live site is fully dark (#0B1F3A background + dark cards everywhere) — the structural opposite. This makes every other Direction C visual fix (cards, spacing, typography) harder to apply without addressing the foundation first.
Fix: Swap the background to #F4F6FA, cards to #FFFFFF with border: 1px solid #E3E7EE. Keep the masthead nav dark navy. Apply color: #1F2937 to body text. This is a CSS token change — if the codebase uses CSS variables or a theme object, it's a targeted swap, not a page-by-page rewrite.
4
Settings / density toggle is invisible in light mode (white on white) High Bug
The settings/density toggle icon in the top-right nav bar is rendered in a light color that disappears against a white background in light mode. Users cannot see or access it.
Fix: Ensure all top-bar icon buttons use a color explicitly set relative to the masthead background, not the page background. Since the masthead will be dark navy, set icon fill to rgba(255,255,255,0.75) and hover to #FFFFFF. Never inherit color from the page body for nav elements.
5
EPM wordmark absent — product identity has no anchor High Visual
The top-left nav shows only an eye/telescope icon. "EPM Market Intelligence" appears only in tiny text at the very bottom of the page. The product has no persistent identity — a user navigating sub-pages never sees the product name. This is especially jarring if the product becomes client-facing.
Fix: Replace the eye icon with a logotype: amber E badge (28×28px, 4px radius) + "EPM Market Intelligence" text in the masthead — matching Direction C exactly. The eye icon can be repurposed or retired.
6
Compact / density toggle — unintuitive control with unclear scope Medium Interaction
The hamburger-style icon in the top bar triggers a "compact mode" whose effect is ambiguous — it's unclear which elements change, and the toggle has no label or tooltip. Users cannot discover it without prior knowledge.
Fix: Replace the icon-only toggle with a labeled button in the nav: a small Dense text button or segmented control ("Normal · Dense") visible only on Markets and Fund Search pages where density is relevant. Show a brief tooltip on hover. Scope it clearly to data tables only — not layout or card size.
7
Card inconsistency — four different card implementations across pages Medium Visual
Stock cards, fund cards, portfolio cards, and news cards all have subtly different internal layouts, font sizes, delta color placements, and description blurb treatments. The product does not feel like one system.
Fix: Define three card variants as shared components: (1) KPI card — metric label + large mono number + sparkline + delta pill; (2) Panel card — titled section with optional sub-content; (3) Table card — padded table with consistent header/row styles. Apply these across all pages. Remove ad-hoc card implementations.
8
Model Portfolios: fund-level cards when portfolio-level hierarchy is needed Medium Interaction
The Portfolio Universe page leads with individual fund cards (BUFR, CGDV, FLQM…) organized as Leaders vs Laggards. Users never see a portfolio-level overview (YTD, Sharpe, risk tier, allocation). The page is extremely long and hard to compare portfolios at a glance.
Fix: Restructure to portfolio-first: two hero cards for featured portfolios with KPI row + allocation bar + CTAs; remaining portfolios as a compact table (Name / Strategy / YTD / 1Y / Sharpe / Risk). Fund-level detail moves to a drill-down page reached via "View holdings →".
9
Forecasting page: gamification elements undermine credibility Medium Visual
The Model Leaderboard section uses trophy and medal icons (🥇🥈🥉) to rank model performance. On a professional financial platform, this framing is jarring — it reads as a game, not a research tool.
Fix: Replace trophy icons with ordinal rank numbers (1, 2, 3) in a muted monospace style. Replace badge/medal metaphors with the Direction C confidence bar (three-segment bar, Low/Med/High). Relabel "Leaderboard" to "Model Rankings" or "Accuracy Summary". Remove all emoji from production UI.
10
Fund Search: missing results list, Deep Analysis Lab dominates Medium Visual
The search page immediately shows a single ticker detail view with no prior results list. The "Deep Analysis Lab" section at the bottom has two large amber CTA buttons that visually compete with the financial data above. The attribution bar ("Powered by Gemini / Anthropic / EPM") is visually noisy.
Fix: Add a results table step before detail view. Demote Deep Analysis Lab to a secondary card with one quiet button. Move attribution to a single footnote line at page bottom in muted mono text.

Implementation brief for Claude Code
How to use this brief. Hand this section directly to Claude Code as the prompt. Each task is self-contained and ordered by dependency. Start with Phase 1 bugs — they are safe, isolated fixes. Phases 2–4 build on each other.
Claude Code · Implementation Brief
EPM Market Intelligence — UI polish pass to align live site with Direction C design system
Context
We have a design reference (Direction C — Executive/Client-facing) that establishes a light-mode, card-based design system with a dark navy masthead, teal accent, amber brand highlight, and soft semantic delta pills. The live implementation diverges from this in several specific ways. This brief covers frontend-only changes — no new backend endpoints needed.
Phase 1 — Bug fixes (do these first)
1A · Settings toggle invisible in light mode
Find the settings/density toggle icon in the top navigation bar. Its color is currently inheriting from the page body and disappearing on light backgrounds. Fix: explicitly set the icon color to rgba(255,255,255,0.75) on the dark masthead, and ensure it never inherits from page background. Add hover state: #FFFFFF at opacity:1.
1B · Empty / loading states on Markets page
Every chart and data panel needs three states: (1) Loading: animated shimmer skeleton at the correct panel dimensions — use a CSS animated gradient from #E3E7EE → #F4F6FA → #E3E7EE; (2) Loaded: actual content; (3) Unavailable: centered icon + "Data temporarily unavailable" message + timestamp + "Retry" button. Remove all plain-text "Loading…" strings.
Phase 2 — Palette & foundation tokens
2A · Switch to light-mode canvas
Find the global CSS token definitions (likely a theme file, tailwind config, or CSS variables). Update:
— Page background: #F4F6FA
— Card background: #FFFFFF
— Card border: 1px solid #E3E7EE
— Card shadow: 0 1px 2px rgba(11,31,58,.04), 0 4px 16px rgba(11,31,58,.07)
— Body text: #1F2937
— Muted text: #6B7688
— Masthead stays: #0B1F3A (dark navy)
Keep existing dark-mode as an opt-in toggle if it already exists; make light-mode the default.
2B · Delta pills — replace raw colored text
Replace all raw color: green / color: red delta values with a Pill component:
Up: background:#E4F3EC; color:#0F8A56; border-radius:100px; padding:3px 10px; font-weight:600
Down: background:#FBE8E5; color:#B3271C; border-radius:100px; padding:3px 10px; font-weight:600
Use monospace font inside pills for numerics.
2C · EPM wordmark in masthead
Replace the eye/telescope icon in the top-left with:
— An amber square badge: 28×28px, border-radius:4px, background:#C28A2B, color:#0B1F3A, font-weight:700, font-size:13px containing the letter "E"
— Text: "EPM" in white 600 weight + " Market Intelligence" in rgba(255,255,255,0.65) 400 weight, font-size:15px.
These should be wrapped in a flex row with gap:12px; align-items:center.
Phase 3 — Persistent navigation
3A · Add section nav links to the masthead — all pages
The top bar currently shows: [eye icon] [search] [density icon] [avatar].
New layout: [wordmark] [nav links] [flex spacer] [search] [avatar]
Nav links: Homepage · Markets · Forecasting · Model Portfolios · Fund Search · Watchlists
Each link: padding:20px 16px; font-size:13px; font-weight:500; color:rgba(255,255,255,0.72)
Active: color:#fff; font-weight:600; border-bottom:2px solid #C28A2B
This nav must appear on every page at the same height, never hidden.
3B · Remove homepage launch cards
The three "Open Markets / Open Forecasting / Open Portfolios" cards on the homepage exist only because navigation is absent. Once the nav is in place, remove these cards entirely. Replace that space with either: (a) the KPI index strip (5 benchmark cards with sparklines), or (b) the hero editorial/news card + calendar right rail from Direction C.
Phase 4 — Page-level polish
4A · Density toggle — label it and scope it
Change the hamburger icon to a small labeled button: text "Dense" with a toggle state ("Normal" when active). Show this button only on Markets and Fund Search pages. When active, reduce table row height by ~30% and hide description blurbs inside cards. Do not change card sizes or layout columns.
4B · Forecasting: remove gamification, add structure
(1) In the Model Leaderboard / Model Rankings section, replace trophy/medal emoji icons with rank numbers (1, 2, 3) in a small monospace circle badge.
(2) Replace colored text confidence badges ("HIGH CONFIDENCE", "MEDIUM CONFIDENCE") with a 3-segment bar: 3 small rectangles (e.g., 18×5px each, gap:2px), filled from left based on confidence level. Low=1 filled, Med=2, High=3. Fill color: #1E7F74.
(3) Add a page header: eyebrow "EPM Research" (teal, 11px, uppercase) + title "Forecasting" (32px, bold, navy).
4C · Model Portfolios: portfolio-first hierarchy
Restructure the page so the first section shows portfolio-level cards (not fund-level). Each portfolio card should show: name, strategy tag, YTD return, 1Y return, Sharpe ratio, risk tier, and an allocation bar. The current fund-level cards (Portfolio Leaders / Laggards) should move to a drill-down page accessible via a "View holdings →" link inside each portfolio card.
4D · Fund Search: demote AI CTA, fix attribution
(1) The "Deep Analysis Lab" section with two large amber buttons should become a smaller secondary card with one button, visually lighter than the financial data above it.
(2) The "Powered by Gemini / Anthropic / EPM" attribution bar should collapse to a single line of muted monospace text at the very bottom of the page: "Analysis powered by Gemini · Anthropic · EPM Models" at font-size:11px; color:#6B7688.
What NOT to change
— Do not change routing logic, API calls, or data models
— Do not redesign the chart components (price charts are functional)
— Do not change the existing dark-mode toggle if one exists — just make light mode the default
— Do not change the Fund Search's ticker detail data tables (Price / Returns / Risk / etc.) — they are good
— Do not change the Forecasting page's consensus forecast data cards — the data structure is correct
— Preserve all existing functionality; these are presentation-layer changes only
